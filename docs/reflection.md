# Sprint 1
We have all contributed to put together a set of endpoints.
The main aspect hindering progress was a matter of personal opinions on design decisions.
As that got out of the way, all endpoints were added quite painlessly when the people responsible for setting up
the database (structure) were finished. 

Unfortunately, there is not a full say from anyone in this regarding how it works, since all the endpoints
need a client to test the entire functionality as a single unit. So far, all "interactive" testing has been done by 
connecting to the Swagger documentation site generated by FastAPI. 

All the parts seemingly work in cohesion based on a walkthrough on all endpoints, with the database restarted with our seed.py.
This help test that no errors occur from the start, by trying each function and seeing no (direct) bug/problem.

In short, all pieces are there, we just need to tie everything together.
